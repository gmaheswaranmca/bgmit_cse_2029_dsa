Infosys Specialist Programmer & Digital Specialist Engineer

## 1. Profile Details

Infosys currently hires freshers into four trainee tracks under this drive. Role assignment is not chosen upfront — it is decided by performance in the same coding assessment used for all levels.

| Role | Package | Track Focus |
|---|---|---|
| Specialist Programmer L3 (Trainee) | INR 21 LPA | Toughest DSA problems; highest coding bar |
| Specialist Programmer L2 (Trainee) | INR 16 LPA | Strong DSA, moderately hard problems |
| Specialist Programmer L1 (Trainee) | INR 10 LPA + INR 1 Lakh Joining Bonus | Solid DSA fundamentals |
| Digital Specialist Engineer (Trainee) | INR 6.25 LPA + INR 75,000 Joining Bonus | AI/ML & Cloud oriented; breadth over depth |

Eligibility Criteria

Degree: BE / BTech / ME / MTech / MCA / MSc (5-year integrated) in CS, IS, IT, AI & ML, ECE, EEE, Software Engineering, or allied CS/IT disciplines

Academic performance: Minimum 60% or 6.0 CGPA (or equivalent) throughout, no active backlogs

Batch: Eligible pass-out years vary by drive cycle — verify the exact batch window on the live posting

Not eligible: candidates who attended any Infosys hiring process in the last 6 months (SE role excluded from this restriction); current Infosys employees

Technical skills: proficiency in at least one language (Java, Python, C or C++) with strong DSA fundamentals

Communication: good written and verbal English — role involves cross-functional and client interaction

## 2. Test Pattern

| Round | Format | Focus Area |
|---|---|---|
| Round 1 | Virtual Online Assessment (Proctored) — approx. 3 hours, 3–4 coding problems (Easy / Medium / Hard / Complex) | Core DSA, algorithmic logic, problem-solving under time pressure |
| Round 2 | Technical + HR Interview (in-person/online, 45–60 min) | Review of Round 1 logic, CS fundamentals (OOP, DBMS, OS), projects, HR fit |

Round 1 — Online Coding Assessment

Duration: ~3 hours (180 minutes), fully proctored

Typically 3–4 problems labeled Easy, Medium, Hard, and (in some cycles) Complex

Each problem carries multiple test cases (commonly ~12) to pass

Allowed languages: Java, Python, C++, C (varies by test portal)

Track cut-off pattern: solving Easy + Medium tends to route toward DSE; solving Hard problems trends toward SP roles; solving Complex/optimal-complexity problems pushes toward higher SP bands (L2/L3)

Solving at least 2–3 out of the total problems with optimal time/space complexity is generally needed to stay competitive for SP shortlisting

Round 2 — Technical + HR Interview

Duration: 45–60 minutes, conducted in-person or via online proctored interview

Starts with a review of your Round 1 solutions — be ready to explain your logic and dry-run time/space complexity on paper

Covers core CS fundamentals: OOP, DBMS/SQL, Operating Systems, Computer Networks

Project / internship discussion, followed by a short HR round on fit and communication

For DSE candidates, expect applied ML/Cloud discussion in place of deep DSA — explaining model choices, cloud deployment decisions, or pipeline debugging

## 3. Technical Agenda — What to Prepare

A. Data Structures & Algorithms (~70% of prep weight)

Arrays, Strings, Linked Lists, Stacks, Queues

Trees, Graphs (BFS/DFS, Dijkstra, shortest path), Heaps

Dynamic Programming (LCS, Knapsack variants, Matrix DP), Greedy algorithms, Backtracking

Sliding Window, Two-Pointer technique, Segment Trees, Binary Search on Answer

Time and space complexity analysis — be ready to justify it out loud

B. Core CS Fundamentals

OOP concepts (in Java or Python) — inheritance, polymorphism, encapsulation, abstraction

DBMS / SQL basics — joins, normalization, indexing, and ACID properties (a recurring interview question)

Operating Systems basics — processes, threads, memory management, scheduling

Computer Networks fundamentals

C. DSE-Specific Track

ML fundamentals and applied model reasoning (why a model/approach was chosen)

Cloud basics — AWS / Azure / GCP concepts

Data engineering / pipeline concepts, debugging applied scenarios

D. Practice Platforms

LeetCode (Easy–Medium for DSE track, Medium–Hard for SP track)

HackerRank

GeeksforGeeks SDE Sheets (specifically recommended by past candidates for Infosys prep)

## 4. Previous-Year Interview Questions (Reported)

Compiled from candidate-reported experiences (GeeksforGeeks, Medium, Glassdoor, Naukri Code360) across 2024–2026 cycles. These are recurring topic patterns, not a guaranteed question bank — the exact questions change every cycle.

Round 1 — Coding Problems Reported

Easy–Medium: Array manipulation using Two-Pointer technique (e.g., find a specific pair sum in a sorted rotated array)

Medium: Dynamic Programming problem — Longest Common Subsequence or a Knapsack variant

Hard: Complex Graph problem — shortest path with constraints, solved using Dijkstra or BFS

Medium: String-based problem

Medium: Prefix sum based problem

Hard: DP-based problem

Hard/Complex: Pack N items of different types into K boxes (consecutive subarrays) such that each box's value equals its count of distinct types, maximizing total value — solved via DP with sliding window + HashMap

Complex: Query-based operations on a 2D list — long problem statement, tricky parsing rather than tricky algorithm

Round 2 — Technical Interview Questions Reported

“Explain the logic of the coding problem you solved in Round 1.”

“What is the difference between a HashMap and a TreeMap in terms of time complexity?”

“Explain ACID properties with a real-life example of a bank transaction.”

“How would you handle a conflict within a development team during a deadline?”

“Walk me through the space complexity of your solution” — candidates were asked to dry-run code on paper to prove efficiency

Core DBMS, OS, and Computer Networks fundamentals questions, mixed with a walkthrough of the OA solutions

Deep dive into your major academic/internship project — design decisions, challenges, and trade-offs

Branch-specific fundamentals for non-CS branches (e.g., core Electrical Engineering concepts for ECE/EEE candidates) before moving to CS topics
